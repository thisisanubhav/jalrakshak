# Current limitations

- Electrical conductivity does not identify arsenic, fluoride, iron, lead, nitrate, pathogens, pesticides, or another specific contaminant.
- JalRakshak does not determine drinking-water safety or issue a certification.
- No physical measurement hardware, ESP32, Bluetooth, or sensor firmware is connected.
- The four-parameter Screening Demo is simulated and uses provisional software rules.
- Experimental EC values are manually entered unless explicitly marked otherwise.
- Repeatability and source-change rules are software assumptions, not validated field or regulatory limits.
- Calibration fields record user-supplied metadata; JalRakshak does not perform or verify calibration.
- No Jhar-Jal, WQMIS, laboratory, or other official government integration exists.
- No institutional field validation has occurred; direct stakeholder validation remains pending.
- Data is local to the current browser, has no authenticated cloud backup, and may be lost if site storage is cleared.
- Map backgrounds require network access unless already cached; local source records remain available through the fallback experience.
- Print / Save as PDF behavior depends on browser print support and is intentionally styled as an investigation record, not an official certificate.
